# road-accident-analysis-india
Road accident risk analysis using SQL, Python, and R
## Overview
This project analyzes road accident data across India (2018–2023, 3,000+ records) to identify patterns in when, where, and under what conditions fatal accidents occur most frequently. The goal is to generate insights that could support road safety planning and awareness efforts.

## Tools Used
- **SQL (SQLite)** — data querying and aggregation
- **Python (Pandas, Matplotlib)** — data cleaning and visualization
- **R** — statistical significance testing (Chi-square test)
- **HTML/CSS** — final report presentation

## Key Findings
- Morning rush hour (7–8 AM) recorded the highest number of fatal accidents, more than late-night hours.
- Fatal accidents are fairly evenly distributed across Indian states, indicating a nationwide issue rather than a localized one.
- State Highways had more fatal accidents than National Highways.
- Cyclist and bus-involved accidents showed the highest fatality counts among vehicle types.
- A Chi-square test showed no statistically significant relationship between weather condition and accident severity (p = 0.196).
